# 确定性城邦与聚落地形生成器

一套确定性的城邦与聚落地形生成能力，用于模拟与可视化工具产出**可复现**的世界：
同一份世界种子和生成参数在任何机器上重复运行，都得到逐字节一致的地图。

- 按可配置分块尺寸生成地形，块间高度、湿度、生态连续无接缝
- 聚落选址受生态与地形适宜度约束，满足最小间距、互不重叠
- 聚落间道路网（MST + A*），不穿越不可通行地形，所有聚落可达
- 支持局部编辑，增量重算与从零重建逐字节对齐
- 多块并行生成，取消/超时不产生半成品，结果与并发度无关
- 地图记录算法版本，旧参数组合永久可复现

## 世界模型

世界（`world.World`）是种子、参数与编辑日志的纯函数：

```
地图 = F(种子, 参数, 编辑日志)
```

### 区块与瓦片

- 世界按**区块**（Chunk）划分，区块边长由 `Params.ChunkSize`（默认 32 瓦片）决定。
- 每个区块包含 `ChunkSize × ChunkSize` 个**瓦片**（Tile），瓦片是最小生成单元。
- 区块坐标 `(cx, cy)` 与全局瓦片坐标 `(tx, ty)` 的关系：`tx = cx*ChunkSize + lx`。
- 每个瓦片记录：高度、湿度、温度、坡度、生态类型，以及道路/桥梁/聚落/不可通行标志。

### 生态分类

生态（Biome）由高度、温度、湿度按 Whittaker 式规则分类：

| 条件 | 生态 |
|------|------|
| 高度 < 海平面 − 0.02 | 海洋 |
| 海平面 ± 0.02 | 海滩 |
| 高度 > 0.86 | 雪地（高山） |
| 热带（温度 ≥ 0.75） | 沙漠 / 稀树草原 / 雨林 |
| 暖温带（≥ 0.55） | 草原 / 森林 / 雨林 |
| 寒温带（≥ 0.35） | 草原 / 森林 / 针叶林 |
| 寒带（≥ 0.2） | 苔原 / 针叶林 |
| 极地 | 雪地 |

### 聚落

- 每个区块在 `CandidatesPerChunk` 个抖动网格点上评估候选地址。
- 候选地址需满足：高于海平面、坡度低于 `MaxSlope`、非海洋/海滩/雪地。
- 评分由平坦度、湿度、海岸可达性决定；低于 `MinScore` 的地址被淘汰。
- 选中地址满足最小间距 `MinSpacing`（欧氏距离），跨区块统一贪心选取。
- 聚落 ID 是 `hash(种子, 全局瓦片坐标)`，名称由 ID 确定性生成。

### 道路网

- 所有聚落构成完全图，边权为欧氏距离；Kruskal 算法求最小生成树（MST）。
- 每条 MST 边用确定性 A* 寻路：陆地代价 1，水域代价 3（桥梁），悬崖（坡度 > `MaxSlope`）不可通行。
- A* 的优先队列按 `(f, g, x, y)` 排序，保证寻路结果与遍历顺序无关。
- 道路网完成后做连通性校验：不在主连通分量中的聚落被确定性移除（仅当悬崖完全隔离某地址时发生）。

## 种子语义

- 世界种子是唯一的随机源，类型为 `int64`。
- 所有随机数都是 `splitmix64(种子, 坐标, 盐)` 的纯函数，**不使用任何全局随机数状态**。
- 不同噪声场使用不同盐值（大陆/山脉/湿度/温度/聚落 ID），彼此独立。
- 种子决定一切：地形、湿度、温度、生态、聚落位置与名称、道路走向。
- 同一种子在任何机器、任何并发度、任何遍历顺序下，生成结果逐字节一致。

## 参数含义

`world.Params` 分组如下：

| 参数组 | 字段 | 含义 |
|--------|------|------|
| — | `AlgorithmVersion` | 算法版本，0 表示当前版本 |
| — | `ChunkSize` | 区块边长（瓦片数） |
| — | `SeaLevel` | 海平面高度阈值（0–1） |
| `Terrain` | `ContinentScale` | 大陆噪声频率，越小陆地越大 |
| `Terrain` | `MountainScale` | 山脊噪声频率 |
| `Terrain` | `MoistureScale` | 湿度场频率 |
| `Terrain` | `Relief` | 高度振幅 |
| `Terrain` | `LatitudeEffect` | 温度随纬度衰减系数 |
| `Terrain` | `CliffSlope` | 悬崖坡度阈值，超过则不可通行 |
| `Settlement` | `MinSpacing` | 聚落最小间距（瓦片） |
| `Settlement` | `CandidatesPerChunk` | 每区块候选地址数 |
| `Settlement` | `MinScore` | 候选地址最低评分 |
| `Settlement` | `MaxSlope` | 聚落最大坡度 |
| `Road` | `LandCost` | A* 陆地代价 |
| `Road` | `WaterCost` | A* 水域代价（桥梁） |
| `Road` | `MaxSlope` | 道路最大坡度 |

**参数隔离规则**：修改某一组参数只影响对应层。例如修改 `Road` 参数不改变地形、湿度、生态或聚落；修改 `Settlement` 参数不改变地形。

## 版本兼容规则

- 每个区块记录生成时的 `AlgorithmVersion`。
- `world.CurrentAlgorithmVersion = 1`。
- **版本 1 的算法永久冻结**：同版本号下，相同种子+参数+编辑日志在任何未来构建中必须产出逐字节一致的地图。测试中的 `TestGoldenHashes` 固定了参考哈希，算法漂移会导致测试失败。
- 新算法以新版本号发布；旧版本号始终可选，不会静默改变已有地图。
- 修改与地形无关的参数（如道路代价）不会改动已有区域的任何字节。

## 编辑语义

编辑（`world.Edit`）是对单个区块瓦片的绝对高度/湿度覆写：

- **幂等**：编辑带客户端选定的 ID，重复提交相同 ID 无效。
- **顺序无关**：若两个编辑覆写同一瓦片，ID 字典序更大的生效，与提交顺序无关。
- **派生字段重算**：覆写高度/湿度后，坡度、生态、可通行性从修改后的值重新计算，不会产生不一致的瓦片。
- **重建等价**：编辑日志是世界状态的一部分；清空区块后重建会重放全部编辑，结果与增量编辑逐字节对齐。

## 确定性保证

生成是纯函数，不依赖：

- 全局随机数状态
- 区块/瓦片遍历顺序
- 并发度或调度顺序
- 运行环境（机器、操作系统、进程重启）

具体措施：

- 所有随机数来自 `splitmix64` 哈希，无状态、可复现。
- 噪声场是全局瓦片坐标的函数，与区块划分无关（跨区块接缝连续）。
- 聚落选址考虑区块 + 8 邻域（halo），候选点与评分都是纯函数。
- 道路 A* 优先队列按坐标确定性格排序。
- 并行流水线不共享可变状态；结果按坐标排序后返回。
- 区块二进制编码不含 map、时间戳等不确定结构。

## 并发模型

`pipeline.Generate` 使用工作池并发生成区块：

- 工作线程数由 `Options.Workers` 控制（默认 `runtime.NumCPU()`）。
- 每个工作线程调用纯函数 `worldgen.GenerateChunk`，不共享可变状态。
- 慢区块不阻塞其他区块（工作线程独立拉取任务）。
- **原子性**：取消或超时后，整批回滚——不写入任何区块，调用方看不到半成品。
- 超时通过 `Options.Timeout` 设置；取消通过 `context.Context`。

## 增量重算

局部编辑后：

1. 重新生成受影响区块（`worldgen.GenerateChunk`）。
2. 调用 `worldgen.RecomputeRoads` 重建道路网。
3. 道路网重建后与从零重建逐字节对齐（`TestIncrementalEqualsRebuild`）。

道路网是世界层面的派生层：编辑地形可能改变道路走廊，受影响区域是依赖闭包（编辑区块 + 聚落 halo + 道路走廊），而非整个地图。

## API 速览

```go
// 创建世界
w, _ := world.New(seed, world.DefaultParams())

// 并发生成区块
chunks, err := pipeline.Generate(ctx, w, coords, pipeline.Options{Workers: 4})

// 单区块生成（纯函数）
ch, err := worldgen.GenerateChunk(w, coord)

// 重建道路网
changed, err := worldgen.RecomputeRoads(w)

// 应用编辑
w.ApplyEdit(world.Edit{ID: "e1", Chunk: coord, Tiles: overrides})

// 清空区块（保留编辑日志），重建时重放编辑
w.ClearChunks()
```
